# Guides

Worked examples with code, from a first Python program to a mobile robot, a leg, a gravity-compensated arm and two
motors coupled over a network, and the SimpleFOC library as an alternative firmware. The CAN commands and the Python
library are the same on STEPFOC, so the code runs there unchanged.

- [Python](python.md): read a driver's position and speed over CAN
- [Mobile robot](mobile-robot.md): two wheels driven from a game controller
- [Quadruped leg](quadruped.md): the kinematics and control of a two-motor leg
- [Gravity compensation](gravity-compensation.md): hold a link against gravity with a current feedforward
- [Bilateral teleoperation](bilateral-teleoperation.md): two motors that follow each other, with force feedback
- [SimpleFOC](simplefoc.md): running the SimpleFOC library on the Spectral Micro instead of the Spectral firmware

More examples are in the [Spectral-BLDC-Python examples](https://github.com/Source-Robotics/Spectral-BLDC-Python/tree/main/examples).
