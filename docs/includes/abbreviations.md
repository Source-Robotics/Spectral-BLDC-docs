*[FOC]: Field-Oriented Control: the motor's current is controlled as a vector relative to the rotor position
*[CAN]: Controller Area Network, the bus between the host and the drivers
*[UART]: the serial port of the driver, 3.3 V, 256000 baud by default
*[PWM]: Pulse-Width Modulation
*[PID]: Proportional-Integral-Derivative controller
*[PI]: Proportional-Integral controller
*[PD]: Proportional-Derivative controller, the impedance control mode
*[EEPROM]: the non-volatile memory on the driver that holds its configuration
*[MCU]: the microcontroller on the driver, an STM32F103CB
*[RTR]: Remote Transmission Request, the CAN frame type that asks a node to send data
*[PCB]: Printed Circuit Board
*[NEMA 17]: the motor frame size whose 31 mm mounting-hole pattern the board uses
*[BEMF]: Back Electromotive Force, the voltage a spinning motor generates
*[SWD]: Serial Wire Debug, the programming interface on the JTAG connector
*[CRC]: Cyclic Redundancy Check
*[LED]: Light-Emitting Diode
