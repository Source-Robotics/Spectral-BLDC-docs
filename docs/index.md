# Index

<!-- doc-meta: spectral -->

!!! note "This is the documentation of firmware 101"
    Firmware 101 is the last documented Spectral Micro release that is flashed with a programming adapter (release 104 adds
    one CAN message, Send_Voltage_Limit, and is otherwise the same). Releases from 105 on carry a bootloader and update
    over UART or CAN; the current version of this site, which the version selector in the header opens, describes them.

**Spectral Micro is in beta stage; the docs and the firmware are under constant development.**

You can buy a [Spectral Micro starter kit](https://source-robotics.com/products/spectral-micro-bldc-starter-kit) or a
[single Spectral Micro driver](https://source-robotics.com/products/spectral-micro-bldc-controller) in the Source Robotics shop.
